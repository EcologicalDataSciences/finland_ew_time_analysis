This contains code used in Gérard et al (2026) (https://doi.org/10.1002/njz2.70072).

The "code" folder contains two files:
- code.R (code for analyses and figures)
- figS4.R (code for Figure S4, that was needed after revision)

The "data" folder contains data needed to run the analyses. Now, it does not contain 2015 data for now but will in the future.

The "derived_data" folder contains results of climate data extraction and derived data created during the analyses, to avoid extraction data when running the code multiple times.

The "figures" folder contains figures in the paper and in Supplementary material in vector.
